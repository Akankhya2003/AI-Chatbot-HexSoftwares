# 🤖 AI Chatbot using Flask  
### 🏢 Developed during HexSoftwares Internship  
---

### 🌟 Project Overview
This project is a **Flask-based AI Chatbot** developed during my **HexSoftwares Internship**.  
It intelligently responds to user questions using **Wikipedia API** and **Natural Language Processing (NLP)** logic.  
The chatbot can handle greetings, small talk, and factual questions dynamically.

---

### 🚀 Features
✅ User-friendly chat interface (HTML, CSS, JS)  
✅ Flask backend to process and generate responses  
✅ Wikipedia API integration for real-time knowledge  
✅ Handles small talk, greetings, and factual answers  
✅ Easily deployable on local or cloud server  

---

### 🧠 Tech Stack
| Component | Technology Used |
|------------|----------------|
| Backend | Python (Flask) |
| Frontend | HTML, CSS, JavaScript |
| API Source | Wikipedia |
| Environment | Virtual Environment (venv) |

---

### ⚙️ Installation & Setup
1. Clone the repository
2. Navigate to the project folder: cd AI-Chatbot-HexSoftwares
3. Install dependencies: pip install flask wikipedia
4. Run the app: python app.py
5. Open your browser and go to: 👉 http://127.0.0.1:5000/
